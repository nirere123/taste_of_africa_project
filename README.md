# Taste of Africa 🌍

## About the Project
Taste of Africa is a website created to showcase the diversity of African food and culture. It introduces visitors to traditional African dishes, their cultural backgrounds, ingredients, and cooking methods.

## What I Did
I developed a multi-page website featuring four traditional African dishes:

- **Nigerian Jollof Rice** – Nigeria
- **Injera with Doro Wot** – Ethiopia
- **Lamb Tagine** – Morocco
- **Bunny Chow** – South Africa

Each recipe page includes food images, cultural information, ingredients, cooking instructions, and YouTube video tutorials to help visitors learn how to prepare the dishes.

## Technologies Used
- HTML – To structure the website.
- CSS – To style the pages and create the layout.
- JavaScript – To add interactive features.
  
## Project Purpose
The purpose of this project is to celebrate African food, share cultural knowledge, and allow people to discover and learn how to prepare traditional African dishes.
